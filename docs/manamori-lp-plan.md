## 1. 何を作るのか

**まな森（まなもり）** ＝ Satoshiさん自作の小学3年生向け学習アプリ。
`github.com/satoshi0207/study3`（private）。Flutter / iOS・Android。**ほぼ完成・ストア未申請。**

Santa Works の**商品ではない**。無料で、収益導線を持たない。
位置づけは **ExifSortPro と同じ「技術力を示す名刺」**（→ `hq/ORG.md` §7）。

### 🔴 LPが先、ストア申請が後

**LPは「申請してから作るもの」ではなく、申請の前提条件。**

- App Store Connect … **プライバシーポリシーURL** と **サポートURL** の提出が必須
- Google Play … **プライバシーポリシーURL** が必須。加えて Data safety の申告

⚠️ **全社の `/privacy` は流用できない。**ストアが求めるのは「**そのアプリの**」ポリシー。

## 2. 読者は親。子どもはこのページを見ない

**構成を決める前に、ここを外さないこと。**

小3が Web ページに辿り着く経路は現実にはほぼ無い。LPに来るのは検索・SNS・リンクを踏んだ人で、
**ほぼ全員が親**。子どもが「やってみたい」と思う場所は LP ではなく、**親のスマホの画面**と
**ストアのスクショ**。

| 媒体 | 読者 | 仕事 |
|---|---|---|
| **LP（このページ）** | **親** | 「これなら入れていい」と思わせる |
| ストアのスクショ | 子ども（親が見せる） | 「やってみたい」と思わせる |

⚠️ ただし **親が子に見せる瞬間がある**（「これやってみる？」）。
だから LP は**見せられる見た目**であること。**文字の壁にしない。**

### 親の「これなら良いかも」の中身

1. **不安の除去** … 広告なし・課金なし・ログインなし・**通信しない**
2. **学習として妥当か** … 学習指導要領に沿った4教科44単元・974問。不正解は即その場で解説
3. **時間** … 1回10問。長く持たせない

🔴 **1が圧倒的に強い。**無料の学習アプリで親が警戒するのは、広告・課金導線・個人情報・
いつのまにか課金。まな森はそれを**設計の絶対条件として最初に潰している**（後付けでは真似できない）。

**普通のLPはこれをFAQの一番下に置く。まな森は逆にする。**ヒーローの直後。

## 5. 必要なスクショの確定リスト 🔴 先に確定させる

**理由：Claude はスクショを撮れるが、アプリを操作できない。**

サーバのセッションから `xcrun simctl io booted screenshot` は SSH 越しに通る（2026-09-01 実証）。
ただし撮れるのは**いま画面に映っているものだけ**。タップは送れない。

→ **Satoshiさんが Mac で画面を進める → Claude がここから撮る**、の分担になる。
→ **後から「あの画面も要る」となると座り直し。**だから撮る前にリストを確定させる。
