# ヒーロー画像の置き場所

この記事（/journal/gourmet-site-dependency/）のヒーロー写真を、このフォルダに
`hero.webp` という名前で置くと、自動的にヒーローに表示されます（置くまではブランドグラデが表示）。

## 仕様
- ファイル名: `hero.webp`（背景画像として center/cover で表示）
- 推奨サイズ: 横 1600px 程度、アスペクトは 21:9 付近がきれい（上下は cover でトリミングされる）
- 形式: WebP 推奨（JPEG を置く場合は `hero.jpg` にして page.tsx の参照を .jpg に変更）

## 素材のルール（サイト共通）
- 商用利用可のフリー素材のみ（Unsplash の通常無料写真など。Unsplash+ / Getty 透かしは不可）
- 人物の顔が主役の写真は避ける（店内・料理・店先など）
- 帰属表示は任意（入れる場合は記事末尾にクレジット）

## 現在使用中の hero.webp
- 出典: Unsplash（A cozy cafe interior with warm lighting and furniture）
  https://unsplash.com/photos/a-cozy-cafe-interior-with-warm-lighting-and-furniture-0i5clWZBit0
- ライセンス: Unsplash License（商用可・帰属表示任意）／人物・顔なしを目視確認済み
- 加工: 1600×686 に横トリミング → WebP(q80)。サイズ 約22KB
